# 最新时序报告导出与分析

目标：把最近一次实现最差的 **2000 条 setup path** 全部导出，工具生成 `timing_paths.csv`（全部路径）和 `timing_summary.md`（全局总结），不再按流水级统计。

## 1. Vivado 导出（一条命令）

打开实现后的设计：

```tcl
open_run impl_1
```

进入报告目录（Windows 下把 `<repo>` 换成你的工程根目录）：

```tcl
cd D:/NSCSCC2026-LLongarch/fpga/nscscc-team/run_vivado/result/for_timing_report/
```

导出全部最差 2000 条 setup 路径：

```tcl
report_timing \
    -setup \
    -max_paths 2000 \
    -nworst 2000 \
    -path_type full \
    -file all_paths_latest.rpt
```

可选：再导一份 WNS/TNS 汇总（不是必须，有更好）：

```tcl
report_timing_summary \
    -setup \
    -hold \
    -max_paths 2000 \
    -file timing_summary_latest.rpt
```

说明：

- `-max_paths 2000 -nworst 2000` = 导出 2000 条最差路径，已经覆盖全部瓶颈；
- 如果之后想导出“全部路径”，把两个 2000 都改大（例如 10000），文件名别覆盖旧的；
- `all_paths_latest.rpt` 里每一条都带完整 Source/Destination 层次和 net fanout，工具靠它分析。

## 2. 运行分析工具（一条命令）

```powershell
cd D:\NSCSCC2026-LLongarch\mytool
python .\analyze_timing_full.py `
    --input D:\NSCSCC2026-LLongarch\fpga\nscscc-team\run_vivado\result\for_timing_report `
    --output D:\NSCSCC2026-LLongarch\fpga\nscscc-team\run_vivado\result\for_timing_report
```

如果报告就在默认目录，也可以直接：

```powershell
cd D:\NSCSCC2026-LLongarch\mytool
python .\analyze_timing_full.py
```

参数：

| 参数 | 作用 |
| --- | --- |
| `--input` | rpt 所在目录，默认 `fpga/nscscc-team/run_vivado/result/for_timing_report/` |
| `--output` | 输出目录，默认与输入相同 |
| `--top N` | 总结里列出的最差路径条数，默认 40 |

工具只统计 Setup 路径，Hold / Pulse Width 自动忽略；`timing_summary_latest.rpt` 里的 WNS/TNS 会被自动读进来。

## 3. 生成的文件

```text
timing_paths.csv   全部去重路径（Slack、Delay、Logic/Route、Levels、Fanout、Source、Destination）
timing_summary.md  时钟周期/主频/WNS/TNS + 全局最差 N 条 + 高扇出网络
```

用 Excel 打开 `timing_paths.csv`（UTF-8 BOM），按 `slack_ns` 升序排列即可看全部 2000 条。

## 5. 判定标准（工具会标在 CSV 里）

| 现象 | 处理方向 |
| --- | --- |
| Slack < 0 | 必须处理 |
| 布线占比 ≥ 70% | 先查长线/扇出/跨模块，再考虑拆级 |
| 逻辑占比 ≥ 50% 或 Levels ≥ 20 | 组合深度问题，拆级、提前译码、拆大 mux |
| 扇出 ≥ 50 | 复制寄存器、全局控制改局部 |

## 6. 优化循环

```text
1. 从 CSV 选 Slack 最小的一条路径
2. 看 Source / Destination 属于哪个模块
3. 判断是布线长、逻辑深还是扇出大
4. 只做一个局部修改
5. 重新综合 + 布局布线
6. 再跑本工具对比 Slack、Delay、Route%、Levels、Fanout
```
